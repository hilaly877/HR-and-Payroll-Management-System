# HR & Payroll Management System

A Windows Forms application developed using C# and .NET Framework to automate Human Resource and Payroll management processes within an organization.

## 📌 Project Overview

The HR & Payroll Management System is designed to simplify employee management, attendance tracking, leave handling, payroll processing, and report generation. The system reduces manual work, improves accuracy, and provides a centralized platform for HR operations.

This project was developed as a university group project for learning software development, database management, and desktop application development using C# and Microsoft SQL Server.

---

## 🎯 Objectives

- Manage employee records efficiently.
- Track employee attendance.
- Handle leave applications and approvals.
- Automate payroll calculations.
- Generate payroll and HR reports.
- Provide secure login and access control.
- Improve organizational efficiency through automation.

## 🚀 Installation

### Prerequisites

- Visual Studio 2022 (or later)
- .NET Framework
- Microsoft SQL Server
- SQL Server Management Studio (SSMS)

### Steps

1. Clone the repository:

```bash
git clone https://github.com/your-username/hr-payroll-management-system.git
```

2. Open the solution in Visual Studio.

3. Create the database in SQL Server.

4. Import the provided SQL scripts.

5. Update the database connection string.

6. Build and run the application.
